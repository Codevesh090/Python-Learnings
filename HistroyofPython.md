🟦 Features of Python language
🟡 Simple and Straight Forward Syntax 
🟡 It is a Case Sensitive Language 
🟡 Multi-Paradigm Programming Language (Matlab ki kya hota hai ki different coding language ko likhne ka style alag-alag hota hai like Java , C# is a Object-Oriented Programing language hai , C is a Procedural Programming Language hai and C++ is both Procedural and Object-Oriented Programming Language hai . Toh yahi different styles ko hum Paradigm kehte hai and kyuki Python ek se zyada programming paradigms (styles/approaches) ko support karti hai like     Procedural Programming ,     Object-Oriented Programming (OOP) ,     Functional Programming ,     Imperative Programming etc. Hence, it is called as a multi-paradigm language)
🟡 Dynamically Typed Language (Matlab like C is a statically typed language which means ki kisi expression ka result kis type ka hoga wo compile time kar hi decide ho jaata hai yaani like  3 + 4.5 = Its result type comes out as "double" and also in C we need to define by ourselves when declaring ki | int a = 5 ; | yaani a is variable whose type is "int" . But yaha python me aisa nahi hota hai , yaha a me humne kya rakha usse automatically decide ho jaata hai , a ki type kya hai like a = 5 , So here we don't have to declare ki a ki type "int" hai . Wo toh automatically decide ho gaya. That's why it is a Dynamically Typed Language )
🟡 Emphasis on Code Readability (Matlab jaise hum kisi aur language me code likhte the but without following "proper indentation" and tab bhi wo code chal jaata tha , but python me aisa nahi hota hai , python me agar code proper indentation and format me nahi likha gaya toh wo nahi chalta hai . Isiliye Python ka code easy to understand hota hai as it is properly written always )
🟡 Python me automatic memory management hoti hai .
🟡 Large Library Support (Python language has highest number of supported libraries than any other language have )
🟡 Python is a system independent or would say platform independent langauge . (Matlab jaise hum C program ko agar humne Windows ke liye banaya hai , toh wo Linux yaa Mac par nahi chalega , But Python ka program har OS par chal jaata hai , ek hi file har OS par run kar sakte ho . )


🟦 Usage of Python 
🟡 Python can serve as a Scripting language for Web-developments (matlab web-application banane ke liye use aati hai python language ) .
🟡 It is used in making Web Framework itself also - Django | Flask etc.
🟡 "Twisted" is a framework to program communications between computers and used by dropbox .
🟡 Pyjs and IronPython can be used in developing the client side of Ajax based applications .
🟡 Libraries like Numpy , Matplotlib can be used in scientific computations .
🟡 Major use of Python is in : Web-Dev | Task automation | Data Analysis | Data visualization 



🟦 Downloading and Installing Of Python (It is same like node but node is for Javascript )
🟡 Jab hum python download karte hai ,it means ki hum yeh sab download kar rahe hai :

📀 Python Standard Libraries (Python comes with thousands of ready-made modules) like we do

import json

Here , math , random , os , json , datetime etc.. is one of python internal library .
📀 pip (Python Package Manager) It lets you install external libraries like " pip i numpy "
📀 IDLE ( Integrated Development and Learning Environment )
Python also installs a small editor called IDLE.
It lets you write and execute Python code without installing VS Code or another editor.
Many people use VS Code instead, but IDLE is included.
