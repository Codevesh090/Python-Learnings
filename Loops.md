🟦 Difference between "for" loop and "while" loop ? Kab konsa loop use karna chahiye ?
🟡 Python me "while" loop ka use aata hai , ki agar hum koi loop run karna hai , untill a condition becomes false . Yaani jab loop, condition ke true , false par dependent ho then we use "while" loop or agar hum chahte ho ki loop chalta hi jaaye jab tak yeh condition false naa ho jaaye then we use "while" loop .Yaani jab ending point indefinite ho , pata hi nahi ho kab end hoga .
🟡 Python me "for" loop ka use aata hai , jab hume definite number of times loop chalana ho and yaani jab loop kisi condition ke true yaa false par dependent naa ho  . Python me loop 'n' times iterate karta hai where 'n' is the number of elements present in iterable-sequence .
