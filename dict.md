dict is a class
dict is mutable
dict is not a sequence (🟢 because it is not a sequence , indexing is not applicable.So, Slicing operator not work also)
dict is iterable
dict elements are "pairs of key-value" data and each key-value pair is called as a item .
dict can have "duplicate data" but "cannot have duplicate keys" .
