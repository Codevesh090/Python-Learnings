🟦 str
str is a class (yaani str is a machine which produces string objects ).
str is iterable
str is immutable (Yaani hum str me insert,append,remove,pop jaise operations nahi kar sakte hai,we can't change anything in it .)
str is hashable 
str preserves the order of string (Yaani str me position of each element matter karti hai , like "hello" likha hai toh str each character "h" "e" "l" "l" "o" ki position ko preserve rakhta hai , dhyan rakhta hai kabhi aage peeche naa ho jaaye ek bhi character, nahi toh us string ka meaning change ho sakta hai )
